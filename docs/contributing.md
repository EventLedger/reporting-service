# Contributing Guidelines

Thank you for contributing! This document outlines how to contribute to the repository and ensure changes integrate smoothly.

## How to Contribute

- Create a feature or fix on a dedicated branch.
- Run tests locally: npm test
- Ensure code style conforms to ESLint/Prettier configuration.
- Add or update tests as needed.
- Update documentation if necessary.
- Submit a pull request with a clear description of changes and rationale.

## Code Style & Quality

- Follow the existing TypeScript coding patterns.
- Use the ESLint/Prettier configuration to format code.
- Ensure pre-commit hooks (if any) pass.

## Testing & Validation

- All tests should pass before merging.
- Include unit tests for new functionality and integration tests if applicable.

## Documentation

- Update docs when adding features or changing APIs.
- Maintain the repository-wide documentation and architecture details.
